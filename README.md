# T.A.C.T
Task Automation & Control Tool
## Development Workflow

### Project Structure
- `Frontend`: front-end application.
- `Backend`: API and services.

### Branch Strategy
- Develop on `develop` branch.
- Create topic branches from `develop` for each task.
- Merge to `develop` only after review and tests.
- `main` is reserved for stable releases.

### Branch Naming
- Use clear names like `frontend/signup-ui` or `feature/login-ui` or `bugfix/api-error-handling`.
- Keep branch purpose focused and short.
